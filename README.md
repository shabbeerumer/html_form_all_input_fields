
# **HTML Basic Elements Project**

### **Overview**
This project is a collection of basic HTML elements demonstrating the usage of form fields, tables, images, unordered and ordered lists, and other essential HTML components. The project serves as a guide for beginners to understand and explore the fundamental building blocks of a web page.

---

## **Features**
- **Form Elements**:
  - Includes all essential input types such as text, email, password, radio buttons, checkboxes, and more.
- **Tables**:
  - Demonstrates how to create structured data tables using `<table>`, `<tr>`, `<td>`, and `<th>` elements.
- **Lists**:
  - Includes examples of both unordered (`<ul>`) and ordered (`<ol>`) lists. 
- **Images**:
  - Shows how to insert images using the `<img>` tag.
- **Basic HTML Elements**:
  - Covers headings, paragraphs, buttons.

---

## **Tech Stack**
- **Frontend**: 
  - HTML5 for structure and layout
